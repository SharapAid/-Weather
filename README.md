# WeatherApp🌤️🌌

A sleek, modern, and high-performance JavaFX desktop application that provides real-time weather information with dynamic UI transitions. Built using Clean Architecture (MVC) and modern UI/UX design principles.

### 🚀 Key Features
* **Dynamic Backgrounds:** Seamlessly switches between deep day and night gradients based on the local time and weather conditions of the requested city.
* **Smart UI & Animations:** Beautiful minimalist layout featuring high-quality Raleway typography, custom weather iconography, and smooth fade-in animations.
* **Robust Data Fetching:** Integrates with real-time weather APIs using a safe background thread environment (`Platform.runLater`) to ensure zero UI freezing.
* **Clean Repository & Build:** Fully managed with Maven, free of IDE junk files, and packaged into a single standalone executable.

### 🛠️ Tech Stack
* **Language:** Java 21
* **Framework:** OpenJFX (JavaFX 21)
* **Build System:** Maven
* **Data Parsing:** org.json
